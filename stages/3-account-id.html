Demo Payments API

Fictional API used for a monitoring tutorial. Version 2.

Authentication

Every request must include your secret key in the Authorization header as a Bearer token.

POST /payments

Use this endpoint to create a new payment for one of your customers.

Request body

ParameterTypeRequiredDescription
account_idstringRequiredID of the account that pays.
amountintegerRequiredAmount in the smallest currency unit, for example cents.
currencystringRequiredThree-letter ISO currency code, for example usd.
descriptionstringOptionalText that appears on the customer's receipt.

Example request

curl -X POST https://api.demo-payments.example/payments \
  -H "Authorization: Bearer $DEMO_PAYMENTS_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "acct_123", "amount": 2500, "currency": "usd"}'

Response

Returns 201 Created with the new payment object.
